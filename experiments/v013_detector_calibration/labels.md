## Coverage / fixture-construction notes

Per Phase 2 Step 0: **pikepdf-synthetic table fixture was NOT constructed** within the 20-min cap. Reason: of the four required generators (Chrome, Word, reportlab, pikepdf-synthetic), three already cover the table-merge case adequately (Word via SOW, reportlab via `reportlab_table.pdf`, Chrome via stat-cards in `chrome_webpage.pdf`). pikepdf-synthetic table coverage is NOT critical because (a) every fixture in `tests/corpus/pikepdf_*.pdf` was generated by us, so we know they don't exhibit table-merge patterns the engine would naturally encounter, and (b) the M10 demo's actual failure was a Word-generated PDF, which is covered.

This makes Phase 2 calibration **partial** on pikepdf-synthetic, **full** on the other three corpora — adequate for v0.1.3 lock-in.
